# HIGH MARKETT — Student Business Website

Website katalog profesional untuk proyek penjualan tas High Markett oleh siswa-siswi SMK Al Aqsyar.

## Fitur
- Hero awal menggunakan logo High Markett, bukan foto produk.
- 15 foto koleksi tas.
- Harga tidak tampil di kartu depan; harga tampil di detail produk.
- Tombol Beli via WhatsApp otomatis mengirim nama produk + harga.
- Pencarian dan filter kategori.
- Link Instagram, TikTok, WhatsApp, dan email.
- Lokasi sekolah yang dapat diklik menuju Google Maps.
- Visi, misi, tim 5 orang tanpa foto.
- Desain abu-abu elegan, animasi reveal, efek 3D dan responsive.

## Jalankan
Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.

## Catatan
Nomor WhatsApp, media sosial, email, dan link Maps sudah diisi sesuai data proyek.


## Struktur file
- `index.html` — struktur halaman
- `style.css` — seluruh tampilan
- `script.js` — katalog, pencarian, filter, detail produk, dan tombol WhatsApp
- `assets/products/` — 15 foto produk
- `assets/logo-high-markett.jpg` — logo High Markett

Jangan gabungkan ketiga file kode. Buka folder ini di VS Code, lalu jalankan `index.html` menggunakan Live Server. Pastikan folder `assets` tetap berada di lokasi yang sama agar semua foto tampil.
